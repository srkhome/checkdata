Failed to Fetch 解決指南

當出現 TypeError: Failed to fetch 時，通常為 Google Apps Script 部署權限設定問題。請按以下步驟確認：

📍 正確的 Apps Script 部署步驟：

  1. 在 Google Apps Script 編輯器右上角點擊 「部署」 (Deploy) ➔ 「新增部署」。
  2. 選擇類型為 「網頁應用程式」 (Web App)。
  3. 執行身分 (Execute as)：選擇 我自己 (Me)。
  4. 誰有權存取 (Who has access)：務必選擇 所有人 (Anyone) 👈（這非常重要，若選成「僅限我自己」會導致 CORS 攔截）。
  5. 點擊「部署」，授予存取權限並複製獲得的新 /exec 網址。
✨ 系統已啟動離線/本機備用機制：
即使沒有網路連線或 API 尚未設定完成，登記與歸還功能依然可正常運作（資料將暫存在您目前的瀏覽器中）。
